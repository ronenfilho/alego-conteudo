## 📝 DICAS DE ESTUDO

```
1. CONHECIMENTOS BÁSICOS (60% da prova)
   ├── Priorize Português e Raciocínio Lógico
   ├── Pratique exercícios de informática (Office)
   └── Estude cronologia histórica de Goiás

2. CONHECIMENTOS ESPECÍFICOS (40% da prova)
   ├── Foque em Machine Learning (conceitos + prática)
   ├── Domine Python para análise de dados
   ├── Conheça as ferramentas de BI listadas
   └── Entenda fundamentos de Deep Learning

3. ESTRATÉGIA
   ├── Resolva questões anteriores
   ├── Crie mapas mentais por disciplina
   ├── Faça simulados cronometrados
   └── Revise pontos fracos semanalmente
```
